I'd like to build an app to use for tryouts for an ultimate frisbee team.  It would allow coaches and supporting staff to watch the tryout and easily note things they see about the players in real time, syncing so that the information can be viewed by the coaches, summarized, etc.  

The most likely platform is mobile, but I'd prefer not having a native app.  However, the easy of use on the mobile platform (and possibly caching and syncing) should be considered. 

There could be as many as 40 players trying out. Having their name and number/pinney color is important. This could be loaded via CSV but also needs to be able to be changed.  Players also need to be able to be updated (change their shirt color and number, or marked absent/injured)

There should be an admin page that coaches can access that allows for adding/uploading the players, but others cannot see. This could just be password protected vs real authentication.  

Support staff and helper coaches could be provided the link, and they just add their name for identification but won't get any of the admin/settings. 

Players should be able to be marked as "no need to watch" because they are well known and not in question of making the team.  It would also be useful to assign groups of players to coaches and supporting staff (with some overlap) as their primary focus during drills so that we ensure coverage.  Maybe named groups (group A) that can be assigned across coaches, and support staff.  

The evaluation criteria should be something we can add with a short name (i.e break throws) and a description. I expect 6 for offensive skills, 6 for defensive skills, and 3-4 others (athleticism, attitude, etc). This should be dynamic but that gives a rough understanding of the number so we can plan the UI.

There should be a list of players, easy to pick the player by clicking their name. Having their button match their jersey color would be ideal. Also an ability to jump to a named group (Group A) to filter the players. 

When selecting a player, the skill or skills should be easily set as standard, above standard, below standard, with possibly "expert" and an equivalent low ranking.  This could translate to 1-3 and 3+ being as good as the best players and 1- or 0 being not under consideration.  Alternatively, red, yellow, green plus the extras for the very top and bottom.  This is an area that is critical to make work well so that it's both easy for the evaluators and intuitive, but also works on the mobile platform. 

Navigating between the lists and the evaluation needs to be simple and effective. Such as going back to the main list or group from the inputting of scores for a player. 

It also needs some ability to add notes (optional) for players, with some pre-set comments, like "I would not consider for the team" or "I would lock for the team" and possible some others.  Drop down to add, plus free form if they want to type. 

As data is input, only coaches can see it (not extra evaluators).  There should be a "finalize" option so the extra evaluators are not able to continue to make changes. A new tryout will happen and a new set of players and groups will happen after that. 

It would be useful to add a player as an example/exemplar for a skill. For example, if a player is great at throwing breaks, for the break throws skill we can say "e.g. Kian" and they would know that Kian is an example of having great break throws.  

It would be nice to be able to "lock" a player and show the roster as is with numbers so we can add a player that is strong enough and lock them so we don't need to further evaluate them.  We can unlock them as well.  Then at a glance we can see the roster and how many spots are taken, how many spots are open, etc.
